Features

Hot Corner

Quickly move the pointer to the top-left corner of any screen to open Mission Control, complete with a GNOME-style ripple animation.

Close Windows in Mission Control

Hold the pointer over a window thumbnail to reveal a close button, just as in the GNOME Activities overview.

Tile Assist

After you tile a window to the left or right half of the screen, a list of other windows appears in the other half, ready to fill the gap.

Green Button Fills the Screen

The green button expands the window to fill the screen instead of entering full screen. Click it again to return to the previous size.

Dark Menu Bar

When a window fills the screen, a black bar appears behind the transparent menu bar, keeping the menu bar readable.

Caps Lock Indicator

An indicator appears centered near the bottom of the screen whenever you turn Caps Lock on or off.

Scroll to Switch Spaces

Scroll over the Apple menu to switch that display to the next or previous space, just as scrolling over the GNOME top bar switches workspaces.

Dynamic Spaces

While you’re in Mission Control, SuperOpt keeps one desktop empty and removes other empty desktops.

Space Indicator

A row of dots shows which space you’re viewing whenever a display switches spaces—whether you switch with the keyboard, Mission Control, a swipe, or a scroll over the Apple menu.

Keyboard and Mouse

Press ⌥

Press the Option key to enter or leave Mission Control.

Press ⌥ Twice

Press Option twice to show or hide the apps window in Spotlight.

Press ⌥1 Through ⌥9

Open apps in the Dock by number. You can choose which number opens the Finder.

Type to Search in Mission Control

Start typing, as you would in the GNOME Activities overview, and Mission Control closes, handing what you typed to Spotlight. You can choose where the search opens: Spotlight or Apps.

Window Tiling

Press Option and an arrow key to tile a window to the left or right half of the screen, fill the screen, or return to the previous size.

Cut and Paste Files in the Finder

Cut, then paste in the Finder to move files instead of duplicating them. Use Command-X and Command-V, or Control-X and Control-V.

Home and End

The Home and End keys move the insertion point to the beginning or end of the current line, as they do on Linux.

Menu Key

The Menu key on Windows keyboards opens a shortcut menu.

Middle-Click Paste

Middle-click in a text field to paste where you click. If text is selected, the selection is pasted—like the X11 primary selection—instead of the contents of the Clipboard. Middle-click an app icon in the Dock to open a new window (or to open the app if it isn’t already open). Middle clicks everywhere else pass through unchanged, preserving each app’s built-in behavior, such as opening links in a new tab in browsers.

Click-Through Focus

One click in an inactive window both brings it to the front and passes through to what’s under the pointer, so pausing a video in an inactive window no longer takes two clicks. It works across apps and between windows of the same app.

Scroll to Zoom in Browsers

Control-scroll in a browser to zoom in and out, with either natural or traditional scrolling.

More Features

Available in 11 Languages

English, Arabic, Chinese (Simplified), French, German, Italian, Japanese, Korean, Portuguese (Brazil), Russian, and Spanish.

Fine-Grained Control

Every feature can be turned on or off in SuperOpt settings, down to individual keyboard shortcuts.

Excluded Apps

Add the apps you want left alone. While you’re using one of them, every feature is off and the menu bar icon dims, so the app behaves exactly as it would without SuperOpt.

Fully Offline and Open Source

No telemetry, no network requests, no data collection. Everything runs locally on your Mac. The full source is on GitHub.

Settings

Install

Install with Homebrew:

brew install --cask logonoff/bucket/superopt

Or download the latest release directly from GitHub Releases, then open the app. Builds are self-signed but not notarized. macOS may block the app the first time you open it. If it does, open System Settings, click Privacy & Security, scroll down, and click Open Anyway. Alternatively, remove the quarantine attribute with xattr -dr com.apple.quarantine /Applications/SuperOpt.app.

Permissions

SuperOpt requires the Device Control and Data Access permission and the Input Monitoring permission in Privacy & Security settings. The app asks for these permissions the first time you open it.

Warning

This project was largely generated by AI, and the code has not been thoroughly vetted by a human. Use at your own risk.

Verification

Every release carries a GitHub artifact attestation that links the build to its source commit and workflow run, confirming that the binary was built from the published source code and hasn’t been tampered with. Verify with gh attestation verify SuperOpt.zip --repo logonoff/superopt.

Releases are immutable. The Homebrew cask pins a SHA-256 hash, and all commits to main are GPG-signed.

The code-signing public key is also available.

Shortcut Remapping

SuperOpt maps Linux keyboard shortcuts to their Mac equivalents—copy, cut, paste, and undo (Control-C, Control-X, Control-V, and Control-Z)—plus shortcuts for browsers, terminals, code editors, the Finder, and more.
